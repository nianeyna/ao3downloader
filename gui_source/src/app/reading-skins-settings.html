A reading skin is CSS of your own, shown on any downloaded work that has no work skin of its own when you open it from FicFairy - a font, a text size, line spacing, a page width, colours. Nothing is written into your files and nothing is asked of AO3; the skin is put in as the work opens, so a new default shows on every work at once. A work's own skin always wins. HTML only.

Write it as an AO3 work skin is written: every rule starts with #workskin, for example #workskin p {{ '{' }} line-height: 1.6; {{ '}' }}.

Which skin is the default is kept in this browser.
